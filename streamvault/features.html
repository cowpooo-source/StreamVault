Web player features

Explore Portal Heaven connection support, browser playback features, direct-first media routing and compatibility limitations.

Supported connections

  • Xtream Codes-compatible APIs
  • M3U playlists
  • Stalker Portal connections
  • Direct HLS URLs

Playback and discovery

Browse live TV, movies and series, search across a connection, view EPG data when the provider supplies it, and resume supported on-demand content.

Direct-first playback

Where browser security and provider behavior allow it, media is requested directly from the provider to the viewer. A compatibility relay can be enabled for exceptional cases, but it is not required for every connection.

Browser limits

Playback depends on the source format, CORS headers, mixed-content policy, codecs, token rules and provider availability. A URL that works in a set-top box is not guaranteed to work directly in a web browser.

Portal Heaven is a player for content sources you are authorized to access. It does not provide channels, movies, or subscriptions.
